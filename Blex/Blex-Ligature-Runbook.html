What you need

Two tools do the work; a third repo carries the ligature glyphs. The ligature and Nerd Font stages run through FontForge's python; the one-time Book (350) step uses plain python3 (fontTools) plus FontForge to flatten glyf→CFF.

Why Ligaturizer

IBM Plex Mono ships no ligatures. Ligaturizer copies Fira Code's ligature glyphs and its calt rules into any monospace font, scale-corrected — so the shapes are Fira Code's, sized to Plex's cell. Both are geometric sans, so they sit together well.

The build

  1. Lay out the sources

    Drop the 16 vendor faces (CFF .otf, copied verbatim from @ibm/plex-mono@2.5.0) into a folder the build reads from.

    Blex/
├── IBMPlexMono/        # vendor sources — IBMPlexMono-{Regular,Bold,Italic,…}.otf ( CFF )
├── IBMPlexMonoVar/     # stage 0 inputs — IBM Plex Mono variable fonts ( wght axis )
├── IBMPlexMonoLig/     # stage 2 output ( ligaturized )
└── IBMPlexMonoLigNF/   # stage 3 output ( Nerd Font )

  2. Synthesize the Book (350) weight

    IBM Plex Mono has no 350 — Light (300) reads a touch thin, Regular (400) a touch heavy. Instance one from the variable font at wght=350 (no glyph editing — the font's own deltas), then flatten glyf→CFF so it matches the OTF vendor set. Run once; the faces are committed.

    bash Blex/blex-book.sh    # → IBMPlexMono/IBMPlexMono-Book{,Italic}.otf

  3. Ligaturize — Plex + Fira Code

    Run from the Ligaturizer repo (it resolves its bundled Fira Code by a relative path). Name the family in one word, like OperatorMonoLig.

    cd /opt/Ligaturizer
fontforge -lang=py -script ligaturize.py \
  Blex/IBMPlexMono/IBMPlexMono-Regular.otf \
  --output-dir Blex/IBMPlexMonoLig \
  --output-name 'IBMPlexMonoLig' --prefix ''    # → IBMPlexMonoLig-Regular.otf ( CFF in → CFF out )

    Looping every weight is enough boilerplate to live in its own script, Blex/ligaturize.sh:

    bash Blex/ligaturize.sh --from ./Blex/IBMPlexMono --to ./Blex/IBMPlexMonoLig

  4. Nerd Font patch

    Patch each ligaturized face. font-patcher keeps the calt table intact and layers the Nerd Font glyphs on top.

    font-patcher Blex/IBMPlexMonoLig/IBMPlexMonoLig-Regular.otf \
  --mono --complete --careful --quiet --no-progressbars \
  -ext otf -out Blex/IBMPlexMonoLigNF

  5. Or wire it into one command

    Stage 2 goes in ligaturize.sh; stage 3 (the Nerd Font loop) stays in build.sh as patchBlex. Then the whole build is:

    bash build.sh --blex    # ligaturize → NF, all 18 faces ( otf-only )

How the ligatures work

There is only one OpenType feature at play: calt (contextual alternates) — the switch editors label “font ligatures”. It never merges characters into one wide glyph; instead each ligature is drawn as single-cell pieces, and calt swaps the typed characters for those pieces. The advance width never changes, so the font stays monospace.

->→ substitutes toCR.35.0  lig.35
!=→ substitutes toCR.27.0  lig.27
===→ substitutes toCR.85.0  CR.85.1  lig.85

A two-cell ligature is two pieces (CR.n.0 + lig.n); a three-cell one is three. Ligaturizer copies 136 such ligatures and the contextual rules that fire them — verbatim from Fira Code, scaled to the target.

Naming & license

IBM Plex is under the SIL Open Font License 1.1 and declares a Reserved Font Name: “Plex”. A modified font may not use that name — which is exactly why the community build is called Blex.

font-patcher handles this for you

Nerd Fonts' font-patcher already renames IBM Plex → Blex on output. So IBMPlexMonoLig-Regular.otf becomes BlexMonoLigNerdFontMono-Regular.otf — RFN-safe automatically. Keep the intermediate IBMPlexMonoLig/ local; ship the Blex… Nerd Font faces.

The output is OFL either way (IBM Plex OFL + Fira Code OFL). Note that Ligaturizer's script is GPL-3.0 — use it as an external tool; the fonts it produces are not GPL.

Verify

Shape a string with HarfBuzz — if -> comes back as ligature pieces, calt survived the Nerd Font patch.

hb-shape --no-positions BlexMonoLigNerdFontMono-Regular.otf 'a -> b'
